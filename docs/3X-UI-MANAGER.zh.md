## 1. 这是什么，以及你需要什么

### 1.1. 应用能做什么

3X-UI Manager 是 3x-ui 面板的**管理客户端**。它连接一个已经在运行的面板，
把网页面板大致能给的东西搬到你手机上：

- 带服务器和 Xray 状态、负载图表和在线客户端列表的仪表盘；
- 完整的**入站**管理——创建、编辑、启用 / 停用；
- **客户端**管理：配额、到期、搜索与筛选、批量操作、分发链接和二维码、IP 记录；
- **节点**（主 / 从多面板架构）管理，包括 mTLS；
- 编辑 **Xray** 配置：出站、路由、DNS、日志，必要时还能以文本方式编辑整份配置；
- 面板本身的**管理**：账号、API 令牌、邮件设置、重启；
- 面板数据库的**备份**；
- 关于问题的**本地通知**：客户端到期、配额用尽、端口不可达、Xray 停止、节点掉线。

### 1.2. 环境要求

| 项目 | 要求 |
|---|---|
| Android | 7.0 或更高（API 24） |
| 3x-ui 面板 | **v3.3.0 或更高**——这是面板开始接受 API 令牌认证的版本。部分能力在更晚的版本才加入，旧面板上不可用 |
| 网络访问 | 手机必须能到达面板地址（直连、经 VPN 或通过反向代理） |

**建议让面板保持最新版本**——这样应用的每个板块都可用，也能获得面板自身的修复。
哪个功能与哪个版本对应，见[第 17 节](#17-面板版本兼容性)。当面板版本低于某项功能所需时，
应用不会隐藏相应板块：而是在板块内提示你的面板版本尚不支持，并建议更新。

### 1.3. 应用不能做什么

这**不是 VPN 客户端**。它不会把手机接入代理，也不会让流量经由代理——它只管理面板。
要真正使用连接，你需要一个普通的客户端应用（v2rayNG、Hiddify、Streisand 等）；
本应用可以帮你把链接或二维码交给它。

应用也不能在服务器上安装或部署面板——面板必须已经部署好。

## 2. 安装与更新

### 2.1. 从哪里获取

| 来源 | 链接 | 说明 |
|---|---|---|
| **F-Droid** | <https://f-droid.org/packages/net.yukh.xui> | 推荐：更新经由商店目录送达 |
| **GitHub Releases** | <https://github.com/yukh975/3X-UI-Manager/releases> | 手动下载 APK |
| **Obtainium** | 添加仓库 `https://github.com/yukh975/3X-UI-Manager` | 直接从 GitHub 自动更新 |

GitHub 的每个 release 附带**两个** APK。普通那个名为
`3x-ui-manager-<version>.apk`——装它就行。`fdroid.apk` 是给 F-Droid
构建服务器用的参考二进制，没有理由手动安装。

### 2.2. 各构建版本的区别

应用有两个构建变体，唯一的区别是更新机制：

- **标准版**（GitHub、Obtainium）可以自行检查更新并提示安装；
- **F-Droid 版**不行，因为商店会自行更新应用，且 F-Droid 的规则禁止应用
  下载并安装自己的 APK。它甚至不携带对应的系统权限。

两个版本用同一把密钥签名，因此可以互相覆盖安装，无需卸载，也不会丢失数据。

### 2.3. 更新如何送达

标准版在启动时检查新版本，并弹出带有变更列表的对话框。文本会跟随界面语言：
选择俄语时显示俄语更新日志，而不是英文发布说明；中文版更新日志暂未提供，
界面会回退到英文。你也可以在**关于 → 检查更新**里手动检查。

在 F-Droid 版中，该按钮替换为一行说明：更新经由商店目录送达。

## 3. 连接面板

应用**使用 API 令牌**连接。不使用管理员登录名和密码——令牌既更安全，
也不会因改密码而失效。

### 3.1. 在哪里获取 API 令牌

1. 在浏览器中打开面板。
2. 进入**设置 → 安全 → API 令牌**（面板英文界面为
   *Settings → Security → API Token*）。
3. 创建一个令牌并复制它的值。

> **3x-ui 的令牌就是完整的管理员权限。** 持有它的人可以在网页面板里做你能做的
> 一切。请像对待密码一样对待它；如果手机丢失，在面板里删掉该令牌，应用就会
> 失去访问权。

### 3.2. 连接表单

| 字段 | 填什么 |
|---|---|
| **面板 URL** | 含协议和端口的地址，例如 `https://panel.example.com:2053`。如果管理员设置了秘密路径（`webBasePath`），要包含进去 |
| **API 令牌** | 从面板复制的值。“显示令牌”可以让你核对是否完整粘贴 |
| **允许自签名 TLS** | 关闭证书校验。仅当面板使用自签名证书时启用——而且只对你自己的面板 |
| **订阅基础 URL**（可选） | 很少用到。应用会自己从面板设置里读取订阅地址；只有公开地址不同时才在这里设置——例如面板在反向代理后面：`https://host:2096/sub/` |

连接成功后配置就会被保存，之后应用会自动重连。

### 3.3. 连接失败时

- **“意外响应”类错误**（界面原文：*Unexpected response — check URL and base path*）——
  通常意味着应用收到的是 HTML 而不是 JSON。地址里少了
  `webBasePath`，或者反向代理用自己的页面做了应答时，就会这样。
- **证书错误**——打开“允许自签名 TLS”。
- **401，或“你的 API 令牌已失效”**——令牌在面板里被删除或禁用了；重新创建一个。
- **毫无响应**——检查手机能否到达面板地址（移动网络、VPN、服务器端的来源 IP 限制）。

## 4. 多面板

应用可以保存任意数量的面板，并在它们之间切换。

顶栏的 **⇄** 按钮打开已保存连接的列表，在那里可以：

- **切换**到另一个面板——每个页面都会针对它重新加载；
- **添加面板**——打开一张空的连接表单；
- 对某个面板**退出登录**——应用会忘掉它的地址和令牌。

当前活动面板会显示在标题栏中，不容易搞混服务器。对最后一个面板退出登录后，
应用回到全新安装的状态——同时会清除应用锁密码。

## 5. 应用锁

由于应用持有的令牌对服务器拥有完全访问权，你可以用密码把它锁起来。
在**设置 → 应用锁**下：

- **设置密码**——4 到 8 位数字；
- **使用指纹解锁**——指纹或面容，若设备支持；
- **移除密码**。

实际行为：

- 启动时，只有在已设置密码且保存的会话被自动恢复的情况下才会要求输入密码；
  如果你刚刚手动输入了令牌，则不会再要求；
- 把应用切到后台会重新上锁，但有 **30 秒宽限期**——快速切到别的应用
  （复制一个地址或看一个验证码）再切回来，不会要求输入密码；
- 用密码或生物识别都可以解锁。

## 6. 仪表盘

第一个标签页。它会自动刷新；下拉列表可立即刷新。

### 6.1. Xray 状态

卡片显示 Xray 是否在运行及其版本。按钮：

- **重启**——使配置更改生效；它会短暂中断所有活跃的客户端连接，应用会就此提醒你；
- **停止** / **启动**。

按下之后，应用会在短时间内保持预期状态，避免滞后的轮询让按钮来回跳动。

### 6.2. 服务器指标

- **CPU**、**内存**、**磁盘**——以百分比显示；
- **网络 ↑ / ↓ 每秒**——当前速率；
- **连接**——TCP 和 UDP 计数；
- **负载 1·5·15 分钟**——系统平均负载。

**交换分区与服务器地址。** 如果服务器有交换分区，CPU、内存和磁盘旁边会出现
交换分区卡片——像其他卡片一样点按即可打开历史；没有交换分区就没有卡片。
服务器的公网地址会分别以 **IPv4** 和 **IPv6** 标注显示，而不是合并成一个地址。

### 6.3. 历史图表

指标块可以点按，打开一段时间范围的图表。间隔可切换（默认是“实时”的两分钟粒度）；
面板保留系统指标历史大约一周。数据来自面板——应用自己不存任何数据。

### 6.4. 在线客户端

在线计数可以点按，打开列表。如果面板接入了节点，列表会按服务器分组，
你能看到谁在主服务器上、谁在节点上。

### 6.5. 本月流量

当前周期内所有入站的流量总计，同样按服务器细分。它由各入站的计数器累加而来；
如果有入站不是按月重置，应用会给出提示——否则这个总和会把按月计数和
全程计数的数据悄悄混在一起。

### 6.6. 面板版本与 Geo 数据库

单独一张卡片显示面板版本，有可用更新时提供**更新**。旁边是 **Geo 数据库**
更新按钮（geoip / geosite）：面板会重新下载它们并重启 Xray。

## 7. 入站

### 7.1. 列表

每个入站是一张卡片：备注、协议、端口、流量计数、到期时间，以及页面打开期间的
实时 ↑ / ↓ 速率。开关用于启用和停用入站；如果面板拒绝了操作，应用会把开关
拨回去并显示错误。

### 7.2. 编辑器：通用字段

- **备注**——你用来辨认它的名字；
- **协议**——VLESS、VMess、Trojan、Shadowsocks、WireGuard、MTProto
  以及面板支持的其他协议；
- **端口**和**监听地址**；
- 整个入站的**流量配额**和**到期时间**；
- **定时流量重置**——包括月内日期，如果面板支持的话（3.6.0）；
- **禁用 XTLS flow**（仅 VLESS，需要面板 3.7.0）——即使传输层允许，
  也阻止面板向此入站注入 `xtls-rprx-vision`。Vision 在你同一订阅的
  其他入站上照常工作；
- **节点**——已接入节点时，选择把该入站部署到哪台服务器。

### 7.3. 传输与安全

传输层（`streamSettings`）通过结构化字段编辑：传输类型（TCP/raw、WebSocket、
gRPC、HTTPUpgrade、XHTTP、KCP 等）、其参数，以及 TLS 或 REALITY 及其字段——
证书、SNI、指纹、short ID。

一个重要细节：应用把传输层作为活动的 JSON 对象来编辑，因此**它不认识的键不会
丢失**。编辑在网页面板中创建、带有冷门设置的入站，不会把这些设置抹掉。

### 7.4. 嗅探、回退与原始 JSON

- **嗅探**——从流量中识别目标，带类型列表；
- **回退**——按 SNI / 路径转发到其他端口；
- **入站 JSON（高级）**——没有做成表单字段的协议设置以原始 JSON 提供。
  客户端单独保存、不会被覆盖：它们在“客户端”标签页管理。

### 7.5. 端口可达性监控

已保存入站的编辑器里有一个“监控可达性”开关。它属于[告警](#13-告警)：
端口和备注会记在**手机本地**，后台探测会直接叩击那个端口，不经过面板。
之所以这样做，是因为面板往往对手机有防火墙拦截，用它来判断健康并不可靠。

## 8. 客户端

### 8.1. 列表、搜索与筛选

列表为每个客户端显示：在线圆点、邮箱 / 名称、相对配额的 ↑ / ↓ 流量、实时速率、
到期时间以及最后在线时刻。

**搜索**不只匹配邮箱——还包括备注、sub ID、UUID、密码、auth 字段和 Telegram ID。

**筛选**（带计数徽标的按钮）与网页面板一致：

- 按状态——活跃、已禁用、已过期、已用尽；
- 按分组。

同一区块内的条件之间是“或”的关系，区块之间各自独立收窄结果——与面板中一致。

### 8.2. 创建与编辑

主要字段：**邮箱 / 名称**、**流量配额**（GB）、**到期时间**、**IP 限制**、
**分组**、**备注**、**Telegram ID**、**subId**，以及绑定到一个或多个入站。

表单会随所选入站的协议变化：

- **MTProto**：出现 FakeTLS 密钥（带重新生成按钮）和广告标签；
- **WireGuard**：对端的 allowed IPs；
- **AmneziaWG**：**转发端口**——面板路由到该客户端的端口和范围，
  如 `80, 443, 8000-8100`；
- VLESS：**flow** 字段。

**续期与流量重置（需要面板 3.7.0）。** 除了熟悉的“每 N 天自动续期”，现在还有：

- **每月续期日**——客户端改为每月在该日期续期，而不是按固定间隔；
  `0` 保持旧模式。当月长度不够时在月末续期；
- **最大续期次数**——自动续期最多触发多少次后就让客户端自然到期；
  `0` 表示不限；
- **客户端自己的流量重置周期**（从不 / 每小时 / 每天 / 每周 / 每月），
  按月时带月内日期。以前重置周期只是入站级设置。

**设备数限制与设备列表（需要面板 3.7.0）。** **设备数限制**限定多少台设备
可以获取该客户端的订阅；`0` 表示不限。“设备”按钮（在已保存的客户端上）
列出已注册的设备——机型和系统，以及每台设备最后出现的时间。设备可以逐个移除，
也可以整表清空：这就是给手机解绑的方式——被移除的设备会在下一次获取订阅时
重新注册。

标识符（UUID、密码、subId）由应用在创建时按网页面板相同的格式生成。

**到期时间精确到分钟。** 选好日期后，应用会询问一天中的时刻；没有到期时间的
客户端默认为 23:59。时间按手机所在时区录入——与面板自带的网页表单一致——
字段下方会标注该时区。如果面板设置了自己的时区，旁边会同步显示面板时钟上的
同一时刻，这样面板在海外、管理员在家里，也不用猜到底按谁的午夜算。

### 8.3. 把配置交给客户端

点按客户端会打开分享面板：

- **订阅**——一条链接，客户端应用由此获取全部配置并保持更新。会显示二维码，
  并有复制和分享按钮；
- **连接**——各服务器单独的链接；每个都可以展开出自己的二维码；
- **“订阅者视角”**——实时订阅状态（在线、已用配额），与客户端自己的应用
  收到的一模一样。需要面板 3.6.0；如果手机访问不到订阅服务器，这一块会直接省略。

**编辑**、**删除**和 **IP 记录**也在这里提供。

### 8.4. 批量操作

长按进入选择模式。对选中的客户端可以：

- **启用**或**停用**；
- **调整**——增减天数和 GB 数、设置 flow；
- **删除**。

### 8.5. IP 记录

显示客户端从哪些地址、什么时候连接过；多面板时还会显示经由哪个节点。
记录可以清空。

记录为空不是故障：面板只在客户端最后一次连接后保留地址 **30 分钟**，
所以最近没有连接的客户端记录为空——应用也会这样说明。

### 8.6. 导出、导入与清理

- **导出**全部客户端为 JSON——可用于备份或迁移；
- **导入**同样的 JSON；面板会跳过邮箱已存在的客户端；
- **删除未绑定的客户端**——移除没有挂到任何入站的客户端。

---

## 9. 节点（多面板）

如果你用一个主面板加多个节点（若干服务器集中管理），这一节很重要。

### 9.1. 列表与状态

每个节点显示名称、地址、状态、其上运行的面板版本和各项计数。开关用于启用和
停用节点。下拉列表即可刷新。

### 9.2. 添加节点

字段包括：名称、协议（http/https）、地址、端口、基础路径、**节点 API 令牌**、
TLS 校验模式，以及**连接使用的出站**（从 Xray 配置的出站标签中选择）。

从面板 3.6.0 起，节点令牌**不会回读**——面板只报告是否已设置。因此编辑时
令牌留空表示“保持现有值”，填入新值则替换。

### 9.3. 双向 TLS（mTLS）

一个独立页面（面板 3.4.0 及更新）。它涵盖两件事：

- **复制此面板的 CA**——以便在节点上把它登记为受信任；
- **受信任的上级 CA**——粘贴管理面板的 CA，使其能将此面板作为节点管理。

有了 mTLS，节点就不需要 API 令牌。

### 9.4. 更新节点上的面板

可以直接从应用里更新节点上的面板。节点会下载新版本并重启，这比一次列表刷新
要久得多——所以应用会持续轮询节点，直到它报告的版本真正变化，然后才显示结果。

---

## 10. Xray：出站、路由、DNS

与 Xray 配置有关的一切都在顶栏的 **⋮** 菜单里。各板块编辑的是同一份配置的
不同部分，每次都整体保存配置——你没有碰过的相邻部分会原样保留。

一个总原则：改动会写入面板的配置，但要在 **Xray 重启后**才到达正在运行的核心。
应用会提醒你；重启按钮在仪表盘上。

### 10.1. 出站

出站列表，显示各自的标签、协议和地址。第一个是默认路由，并有相应标注。可用操作：

- **创建和编辑**出站：协议、地址、端口、凭据、传输，外加**目标策略**
  （从 `AsIs` 到 `ForceIPv4`）和“发送经由”；
- **排序**——用上 / 下箭头；顺序决定哪一个成为默认路由；
- **删除**；
- **从 `vless://` 链接导入**；
- 以 JSON **导入和导出**整个列表。

### 10.2. 测试出站

每个出站都有**测试**按钮，带模式选择器：

| 模式 | 测什么 |
|---|---|
| **TCP** | 连接层面的可达性与延迟 |
| **HTTP** | 经代理发起完整请求；还会报告出口 IP 和国家 |
| **真实延迟** | 包含隧道建立的总时长——最接近真实体验 |

使用 HTTP 和真实延迟模式时，延迟旁边还会显示 IP、国旗，以及出口经由
**WARP** 时的标记。探测所用的 URL 在面板一侧设置。

### 10.3. 出站订阅

面板可以按定时从订阅地址拉取别人提供的服务器列表，并将其作为出站并入配置。
该板块从“出站”页面的 **⋮** 菜单进入。

每个订阅可配置：

| 字段 | 含义 |
|---|---|
| **订阅地址** | 面板从哪里获取列表 |
| **备注** | 你用来辨认它的名字 |
| **标签前缀** | 例如 `hk-`，用于在路由中区分它的服务器 |
| **更新间隔** | 面板多久重新读取一次该地址 |
| **已启用** | 临时关闭而不删除 |
| **置于手动出站之前** | 把它的服务器排到你自己的前面——之后其中一台可能成为默认路由 |
| **允许私有地址** | 允许指向本地 / 局域网地址的 URL；出于安全默认关闭 |
| **允许不安全的 TLS** | 用于自签名证书的来源 |

操作：**预览**（保存前，面板先拉取并解析该地址，显示找到多少服务器、
都是什么标签）、**立即刷新**、**全部刷新**、排序和删除。

来自订阅的服务器会在“出站”页面单独成块。它们可以像普通出站一样**测试**，
也可以用于路由规则和负载均衡，但**不能直接编辑**：每次订阅刷新面板都会
重新生成它们，任何编辑都会被覆盖。请通过订阅本身来修改。

### 10.4. 路由与负载均衡

**路由**板块包含：

- **规则**——按域名、IP、端口、协议、入站；每条规则指向一个出站或一个
  负载均衡。规则可以启用 / 停用、重新排序、导入和导出；
- **负载均衡**——出站分组，带选择策略（`random`、`roundRobin`、`leastLoad`、
  `leastPing`）；
- **默认出站**——处理未匹配任何规则的流量。

内部统计规则（`api`）受保护、不可停用——没有它流量统计会失灵。

### 10.5. 路由测试

这个工具回答“这个地址会走向哪里”。输入域名或 IP，可选端口和网络类型，
**选择一个入站**——然后你会得到最终出站、负载均衡链（如果有），
或“默认出站”的判定。

选择入站是必选项而非可选项：几乎所有路由规则都以入站为条件，没有它路由器
无法判断。该测试只对本地入站有效；主面板没有针对节点入站的路由规则，
所以对它们的结果没有意义。

### 10.6. DNS

DNS 部分的编辑器：服务器（普通和条件）、查询策略，以及静态 hosts 条目。

### 10.7. 常规设置与日志

**常规 / 日志**板块：日志级别、日志访问参数以及其他核心常规设置。

### 10.8. Geo 数据自动更新

仪表盘上的 Geo 数据库按钮（见 [6.6](#66-面板版本与-geo-数据库)）只是
**手动拉取一次**。本节配置的是同一件事的**定时执行**：Xray 自己下载列出的
文件并重新加载，无需重启。需要面板 3.7.0。

- **计划**——五段式 cron 表达式，例如 `0 4 * * *`（每天凌晨 4 点）。
- **通过出站下载**（可选）——列表来自配置里的出站标签。留空表示走常规路由。
- **文件**——文件名和它的获取地址。URL 必须是 **HTTPS**，文件名要像
  `geosite_custom.dat` 这样的普通名字，不能带路径。

保存前应用会检查这三项约束，不合规的组合不会被放行。删掉最后一个文件会把
整个计划块从配置中移除——没有文件的计划毫无意义。

还有一条约束来自 Xray 自身：**文件必须先在面板的 `bin` 目录里存在过一次**，
否则没有东西可更新——所以先通过仪表盘按钮或手动放入，之后计划会持续保持它
最新。路由规则以 `ext:geosite_custom.dat:category` 这样的形式引用此类文件。

### 10.9. 完整 Xray 配置

如果某个需要的字段任何表单里都没有，可以直接以文本编辑配置——整份配置，
与面板的 Xray 配置页相同的 JSON。旁边的出站测试 URL 也在这里设置。
保存需要重启 Xray。

## 11. 面板管理

**面板管理**板块（**⋮** 菜单）汇集面板自身的设置。

- **管理员账户**——修改登录名和密码。需要输入当前凭据。修改后你的 API 令牌
  继续有效，但其他浏览器会话会被登出。
- **API 令牌**——面板的令牌列表：启用、停用、删除、创建。新令牌的值只显示
  **一次**——请立刻复制。删除某个令牌会立即切断所有使用它的应用。
- **订阅**——**公告**文本（`subAnnounce`），在订阅信息页以横幅显示。
- **邮件（SMTP）**——面板邮件的发件地址和名称。地址留空则回退到 SMTP 用户名。
  当中继的登录名不是邮箱地址时这一点很重要：没有有效的 `From`，Gmail 等
  严格的收件方会拒收。需要面板 3.6.0。
- **通知**——**出站故障阈值**：连续多少次探测失败后，面板才发送出站不可达的
  告警。`1` 表示旧行为，第一次失败就告警。它有助于在链路不稳时避免误报刷屏。
  需要面板 3.6.0。
- **重启面板**——重启面板服务本身；应用的连接会中断几秒钟。

## 12. 备份

**备份 / 恢复**板块。

- **下载**——应用拉取面板数据库并询问保存位置。文件名由面板决定：SQLite 为
  `x-ui.db`，PostgreSQL 为 `x-ui.dump`。
- **恢复**——选择一个文件；面板用自己的数据库引擎导入它并重启 Xray。

该数据库装着**一切**：面板设置、入站、客户端和 Xray 配置。因此备份是迁移到
另一台服务器最快的方式——同样因此，它是一份应当视同机密对待的文件。

## 13. 告警

### 13.1. 工作原理

告警**完全在本地**。应用自身大约每 30 分钟轮询一次已保存的面板并发出系统通知。
不涉及任何外部推送服务：你的数据和面板地址都不会外流。代价是告警要到下一次
检查时才出现，而不是在同一秒出现。

可达性检查是 **TCP 端口层面**的，不走面板 API。原因很简单：面板往往对手机
有防火墙拦截，它不可达说明不了服务的健康状况。默认探测 **443 端口**——
通常的公开入口。

为了避免虚惊，不可达告警只在**连续两次检查失败**后触发；认证错误（401）
不算作不可达。

### 13.2. 告警类型

| 告警 | 何时触发 |
|---|---|
| **客户端已到期** / **即将到期** | 到期时间已过，或距到期不足配置的天数 |
| **流量即将用尽** | 已用超过配置的百分比 |
| **面板不可达** | 配置的端口无响应 |
| **入站不可达** | 标记为监控的入站的端口无响应 |
| **Xray 已停止** | 核心没有在运行 |
| **节点离线** | 节点掉线 |

通知分为**两个系统渠道**——客户端类和基础设施类。这样你可以在 Android 设置里
静音客户端类的絮叨，同时保留服务器告警。每条通知都带有触发日期和时间，
几小时后看到它时，也能判断问题是否还在当下。

### 13.3. 配置

在**设置 → 面板告警**下：

- **启用**开关（Android 13+ 上应用会请求通知权限）；
- **到期前天数**——提前多久提醒（默认 3）；
- **流量阈值（%）**——用到多少时提醒（默认 90）；
- **面板端口**——探测可达性用哪个端口（默认 443）。

单个入站从各自的编辑器加入监控——见 [7.5](#75-端口可达性监控)。

## 14. 应用设置

- **语言**——**跟随系统**（默认）、English、Русский 或中文。系统模式下应用
  跟随手机语言，你改语言后立即切换，无需重启。显式选择始终优先于系统语言。
- **速度单位**——字节（KB/s）或比特（Kbit/s）。适用于入站和客户端速率。

- **检查更新**（在 F-Droid 版中替换为一行说明：更新经由商店目录送达）；

## 16. 隐私与安全

**应用连接到哪些地方。** 只连接你自己输入的地址：你的面板，以及在把订阅
交给客户端时的订阅服务器。此外，标准版还会访问应用自己的 releases 页面
以检查更新。应用内没有任何分析、广告或跟踪器。

**F-Droid 版完全不接触我们的基础设施**——它连更新检查都没有。说实话的
副作用是：我们无从知道有多少人通过商店目录使用这个应用。

**你的数据如何存储。** 连接配置（面板地址和 API 令牌）存放在 Android 的
加密存储中：值以 AES-256-GCM 加密，密钥以 AES-256-SIV 加密，主密钥保存在
Android Keystore 里。此外，进入应用还可以用密码和生物识别来锁定。

应用请求的**权限**：

| 权限 | 用途 |
|---|---|
| 互联网和网络状态 | 与面板通信 |
| 通知 | 本地告警 |
| 生物识别 | 指纹 / 面容解锁 |
| 安装软件包 | 仅标准版——用于安装更新；F-Droid 版没有该权限 |

**请记住。** 3x-ui 的 API 令牌是完整的管理员权限。“允许自签名 TLS”模式会
关闭证书校验，只适用于你自己的面板。

## 17. 面板版本兼容性

**最低要求的面板版本是 3.3.0**：面板从这个版本开始接受整个应用所依赖的
API 令牌认证。在这个版本的面板上，应用可以运行，但有些能力是更晚的面板
版本才加入的：

| 能力 | 需要的面板版本 |
|---|---|
| API 令牌登录、仪表盘、入站、客户端、订阅、Xray 配置 | 3.3.0 |
| 出站订阅 | 3.3.1 |
| 节点与 mTLS、客户端 IP 记录、客户端导入导出、入站实时速度、在线客户端按服务器拆分 | 3.4.0 |
| 客户端批量操作、VLESS 加密密钥生成 | 3.4.1 |
| 客户端实时速度、出站测试、目标策略、路由测试、订阅公告、MTProto 和 WireGuard 客户端字段 | 3.5.0 |
| SMTP 发件设置、出站故障告警阈值、“订阅者视角”状态、只写节点令牌、按月的流量重置日 | 3.6.0 |
| 每月按日续期、最大续期次数、客户端自己的流量重置周期、设备数限制与设备列表（HWID）、AmneziaWG 转发端口、API 令牌范围与有效期、IP 限制白名单、禁用 XTLS flow、重新加载主面板的 mTLS 凭据、Geo 数据自动更新 | 3.7.0 |

**建议很简单：用最新的面板。** 这样应用的每个板块都可用，沿途也能获得面板
自身的修复。

如果面板版本低于某个板块所需，应用**不会把它隐藏**——而是给出说明：
你的面板版本不支持此功能，请更新面板。这样你能看到功能的存在，也知道该怎么做。

## 18. 故障排除

**“意外响应”或解析错误。** 应用收到的东西不是 JSON。最常见的原因是面板地址
缺少秘密路径（`webBasePath`），或者反向代理拦截了请求。从浏览器复制完整地址
来核对。

**证书错误。** 在连接设置里打开“允许自签名 TLS”——但只对你自己的面板。

**“你的 API 令牌已失效”。** 令牌在面板里被删除或禁用了。新建一个再连接；
其余项会由已保存的配置自动填好。

**某个板块提示面板不支持该功能。** 面板版本低于要求——见[第 17 节](#17-面板版本兼容性)。
从仪表盘更新它。

**Xray 的改动没有生效。** 配置已保存在面板里，但要在 **Xray 重启后**才应用——
按钮在仪表盘上。

**收不到告警。** 检查设置里是否已启用、Android 是否授予了通知权限、电池优化
是否在杀掉应用。记住检查大约每 30 分钟跑一次，不可达要在连续两次检查失败后
才上报。

**路由测试总是“默认出站”。** 没有选择入站——规则几乎都以它为条件。
对节点入站而言结果没有意义：主面板没有针对它们的路由规则。

**应用更新迟迟不到。** F-Droid 版的更新只经由商店目录，会在发布后一两天
出现——那是他们构建服务器的节奏，不在我们的控制之内。
